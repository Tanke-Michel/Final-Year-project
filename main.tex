\begin{abstract}
Deploying Large Language Models (LLMs) on edge devices for clinical question answering requires balancing low memory footprints with high safety retention. This study evaluates five quantization and fine-tuning paradigms (FP16 baseline, LoRA, QAT4, QLoRA4, and PTQ4) using Qwen2.5-0.5B-Instruct on the AfriMedQA dataset. We measure clinical response quality, safety refusal retention via a rule-based guardrail, and parameter compression floors.
\end{abstract}

\section{Methodology}
We evaluate the target architecture across five distinct experimental arms:
\begin{itemize}
    \item \textbf{FP16:} Uncompressed 16-bit reference baseline.
    \item \textbf{LoRA:} Low-Rank Adaptation fine-tuning in FP16 precision.
    \item \textbf{QAT4:} 4-bit Quantization-Aware Training simulating quantization noise during training.
    \item \textbf{QLoRA4:} 4-bit NormalFloat (NF4) base model coupled with FP16 adapter weights.
    \item \textbf{PTQ4:} Post-Training Quantization applied directly to fine-tuned weights.
\end{itemize}

\section{Results \& Discussion}
